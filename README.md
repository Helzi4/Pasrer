## Auto Parser


## What it does:

This script is used to parse logs from Apache-like access logs. The parser is also tested with pytest.
It's my first Python script, I created it to learn python and basic security log analysis.

## Features:
1. parse Apache-like logs
2. count requests by status/method/IP/path
3. detect 401/403 activity by IP
4. filter suspicious IPs by threshold
5. output result in JSON format
